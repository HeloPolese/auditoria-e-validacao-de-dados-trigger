# Sistema-de-Auditoria-e-Valida-o-de-Dados-com-Triggers
Projeto de banco de dados financeiro utilizando Triggers MySQL para implementar validações automáticas, regras de segurança, auditoria e geração de logs. Inclui bloqueio de dados inválidos, preenchimento automático de campos e rastreamento de operações com uso de OLD e NEW.
